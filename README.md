# Data-PreProcessing-Sample
This project in Jupyter Notebook implements a data cleaning and exploratory analysis pipeline for the Life Expectancy dataset. The workflow is designed to transform raw health data into a model-ready format.
In addition, it also contains the Jupyter notebooks and exercises for Solving Mathematical, Physical and Chemical Problems. The notebooks cover scientific programming, numerical computing, data analysis, visualization, and scientific data processing using Python libraries such as NumPy, SciPy, Pandas, Matplotlib, and Seaborn.
